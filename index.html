QUICK GUIDE

Make your first animation

  1. Add a layer. Use Add above the canvas to choose a shape or import artwork.
  2. Set a moment. Move the playhead, then drag, resize, or edit the layer. Add a keyframe to save a change.
  3. Make it move. Open Animate to draw a move, add rotation, or fade a layer away.

Press Ctrl + Z to undo. Use Play to preview, then Export when ready.
