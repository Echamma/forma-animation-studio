# Forma — shape animation studio

This is the **Linux desktop branch**. The original browser app is preserved on `main`.

**Forma 1.1.0 adds an MCP server for Codex and Claude.** It can edit the live scene, animate layers, inspect PNG frames, import artwork, and export projects, PNG/SVG, and WebM. Download the desktop app and the bundled `forma-mcp.cjs` from [the release](https://github.com/Echamma/forma-animation-studio/releases/tag/linux-v1.1.0). A Windows portable app is included alongside the Linux packages. Click **MCP off** in the desktop header to enable control. See [MCP setup and tool documentation](mcp/README.md) for installation and configuration.

Download the x86-64 AppImage or Debian package from [GitHub Releases](https://github.com/Echamma/forma-animation-studio/releases). For the AppImage, run `chmod +x Forma-Animation-Studio-1.1.0-x86_64.AppImage`, then `./Forma-Animation-Studio-1.1.0-x86_64.AppImage`. If FUSE is unavailable, use `./Forma-Animation-Studio-1.1.0-x86_64.AppImage --appimage-extract-and-run`. For Debian/Ubuntu, install with `sudo apt install ./Forma-Animation-Studio-1.1.0-amd64.deb` and launch Forma from your application menu.

To develop on Linux, install Node.js 22, run `npm ci`, then `npm start`. `npm run build` creates AppImage and `.deb` packages. `npm test` checks editing, animation state, PNG/SVG output, and saving recovery data when closing. Headless test environments need Xvfb: `xvfb-run -a npm test`. GitHub builds and tests this branch on Ubuntu 22.04 and publishes packages with SHA-256 checksums after successful checks.

The desktop app autosaves each named project locally as you work and restores the latest scene when it reopens. Rename the project in the header, use **New project** to start another, and use **Projects** to reopen one saved on this device. Press **Ctrl+Z** to undo an edit. The previous session is kept as a separate recovery copy. Processing and exports run locally. The optional Google Fonts stylesheet uses system fonts when offline.

Open `index.html` in a modern browser. No installation or build step is required.

1. Add a rectangle, circle, triangle, diamond, or arrow. Arrow layers support the same resizing, rotation, motion paths, keyframes, colors, and exports as other shapes.
2. Select a layer, then drag it or edit its position, size, keyframe rotation, opacity, and fill. Use **Layer angle** or drag the round handle above the selected object to turn an image, SVG, video, or shape at every point in the scene without creating an animation.
3. Use **Image, SVG, or video** to import several PNG, JPEG, WebP, SVG, MP4, WebM, or Ogg files at once, or drag files onto the editor. Each becomes a layer in the saved project. Forma does not impose a file size cap; very large media still depends on available device memory and disk space.
4. Select an SVG layer and choose **Edit SVG artwork**. Click a visible part to change its fill or stroke, delete a part, recolor the whole artwork, or edit its markup. SVG markup is sanitized locally before it is added to the canvas.
5. Move the timeline playhead and adjust a shape or media layer to create a keyframe automatically. Use **Add keyframe** to hold its current pose at another time. Right-click a timeline diamond to move it to a precise time or delete it. Editing a keyframe from a drawn motion converts that motion into regular editable keyframes.
   Select a layer on the canvas to reveal eight resize handles. Drag a corner to scale it proportionally, hold Shift while dragging a corner to stretch it freely, or drag a side handle to change one dimension. Resizing at a moment on the timeline updates that layer's keyframe.
   Select any layer and use **Edit → Look → Blur** to soften it from 0 to 100 px. Blur applies to shapes, images, SVG artwork, text, and video in previews and exports.
6. To animate an entrance, select a keyframe and use **Place outside frame** (Left, Right, Above, or Below). The surrounding pasteboard keeps off-frame layers visible and draggable while editing. Middle drag outside the canvas to pan the workspace; scroll to zoom. Move the playhead and position the layer inside the frame at another keyframe.
7. Under **Draw motion**, choose **Draw destination arrow** and drag on the canvas to send the layer to the arrow tip. Choose **Record mouse path** and hold-drag to make it follow the path you draw. Set the movement duration before drawing. Each drawn animation gets its own timeline clip beneath the shape. Select the clip to edit its start, length, distance, spin, and direction; drag the clip to move it or its right edge to resize it. Use **Preview this animation** to play just that clip, or enable automatic preview while editing.
   Under **Quick animation**, choose **Drop selected item onto screen** to make the selected layer fall from above, squash on impact, and bounce into its current position. Set the drop length first. The effect starts at the playhead, creates editable keyframes, and previews automatically.
8. Add a separate rotation animation to any shape or select an existing move first to match its timing. Rotation appears as its own purple timeline clip and can be moved, resized, eased, previewed, and edited in degrees. It combines with the underlying movement without replacing it. You can also add a spin in degrees to rotate the layer while it moves. Enable **Rotate to face movement** to align it with the arrow or with each turn in a freehand path. These options can be combined.
   Under **Disappear**, add a fade out to any layer. Choose its start and length, then keep it hidden indefinitely, reappear at a set time, or reappear when another layer's keyframes, move, or rotation finish. The linked timing follows edits to that animation. A red clip on the timeline shows the hidden interval.
9. Press Play to review the animation. Video layers synchronize to the scene timeline and play their original audio. Playback clips everything outside the artboard. Click a timeline diamond to inspect a keyframe. Choose smooth, linear, or hold interpolation per layer.

Forma restores the most recent autosave when it opens. If a local `default-project.json` is present in Forma's user data folder, **Load default project** opens that saved scene and Forma uses it if the recent session is missing.
10. Export an animated SVG, video, or PNG of the current frame. Video export includes live frames and audio from imported video layers. Animated SVG uses a poster frame for video layers because portable SVG viewers do not reliably support embedded video. Keep the browser tab visible while recording video. The format depends on browser support, usually WebM.
11. Use **Open project file** to import an existing editable JSON project into the local project library. Imported media is included in Forma's local autosave. The browser-only version does not provide the desktop autosave service.

Choose 960 × 600 landscape or 1080 × 1920 portrait (9:16) under Scene Settings. Changing formats scales existing shape positions and sizes. Scene duration can be extended beyond 30 seconds without moving existing keyframes or clips. Increasing an animation or rotation length beyond the scene end extends the scene automatically. Animated SVG samples motion up to 60 frames per second, with an adaptive cap for very long scenes, and loops indefinitely. Color is constant per shape; position, size, rotation, and opacity are animated.

Choose a background from the quick swatches in the left toolbox or use the adjacent custom color picker. The same color remains available under Scene Settings and is included in every export.

Fonts use Google Fonts when available and system fallbacks otherwise. All animation and export processing runs in the browser.
