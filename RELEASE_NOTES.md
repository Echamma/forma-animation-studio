# Forma Animation Studio — Linux 1.0.0

Linux desktop packaging of the Forma animation editor, with shapes, keyframes, motion paths, linked text, SVG/image/video imports, and local PNG, animated SVG, and video exports.

Closing the desktop editor preserves the current animation in a local recovery file. Save project exports a portable editable JSON file.

Includes x86-64 AppImage and Debian/Ubuntu `.deb` packages. See the README for launch and installation instructions. The original browser app remains on the `main` branch.
